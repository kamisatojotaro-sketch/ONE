# 🌿 ONE — Personal Media & Study Tracking Platform

> A cozy, editorial personal media tracker covering **Games**, **Movies**, **Anime**, **Music**, and **Study Notes** — built with React 19, Vite, Tailwind CSS v4, and IndexedDB.

---

## ✨ Features

- 🎮 **Games**: Track backlog, active plays, and completed games with cover art and genres via the RAWG API.
- 🎬 **Movies**: Log watched films, ratings, and reviews powered by TMDB metadata.
- 📺 **Anime**: Catalog anime series, movie adaptations, and episodes watched via Jikan (MyAnimeList) API.
- 🎵 **Music**: Personal music tracking and listening statistics dashboard.
- 📚 **Study Notes**: Markdown-enabled study companion with categorization, tagging, and pinning.
- 🔒 **100% Offline & Private**: All data stored locally in your browser with IndexedDB via `idb`. Zero mandatory accounts or cloud dependencies.
- 🎨 **Cozy Editorial Aesthetic**: Warm, soft paper light theme and atmospheric mossy dark theme inspired by editorial print magazines.

---

## 🛠️ Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build
```
